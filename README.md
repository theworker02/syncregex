# syncregex

Sync timestamps and regex durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/syncregex/

## Install / run

```bash
git clone https://github.com/theworker02/syncregex.git
cd syncregex
node src/cli.js
node --test
```
